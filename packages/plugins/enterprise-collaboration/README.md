# 企业协作插件

这是显式安装的外置插件，不加入 Desktop 默认发行清单。与企业身份插件配合，在原生 DSH 会话中提供同事通讯录，并在侧栏提供“协作”信息列表。共享事实和文件副本存于独立 Spring Boot 服务；双方的身份、会话和工作区仍然独立。

## 从会话分享

完成分析后，在原生输入框输入 `@`，按姓名或邮箱找到同组织同事。选中后直接点击发送，不必再输入说明；选中本身不会发送。材料确认框展示本次提问、最终分析、可勾选的原始资料与生成成果。确认后才保存分享并通知同事。系统提示、推理、工具日志和其他会话不共享。

生成成果来自本轮官方 `deliverables/presented` 事件，使用会话 scoped filesystem 校验工作区包含关系，再读取并冻结为官方附件副本。不会从模型文字猜测任意路径或扫描磁盘。未导出的在线文档不作为已生成文件；正式成果无法读取时明确报错，不静默漏掉。更早一轮上传的原始资料会提示核对。

## 接收与交流

在线通知显示“查看分享”；点击直接展示共享正文和文件下载，不创建 AI 会话、不调用模型，也不默认要求复核或完成待办。侧栏“协作”展示收到/发出的信息列表，详情内可以直接回复同事。只有主动点击“用 AI 继续处理”，才创建本人原生会话草稿，由用户发送。

当前每 2 秒轮询通知及讨论，查看标记相关通知已读。“稍后处理”只隐藏提醒。兼容早期交接记录，已完成的历史记录只读；新分享不使用默认完成流程。旧分享不会自动补上以前漏掉的文件，需从原会话重新分享。

## 公开接口与权限

复用官方 `inputTriggers.registerSource`、CommandClaim、Session inspect、附件 API、deliverables 事件、scoped filesystem、Host Connection、Client Slots 和 MarkdownText。当前源码精确锁定官方 DSH `0.2.0-rc.2` / Cordis `4.0.4`；不修改 Harness 源码。当前运行与验收范围见[验收要求](../../../apps/web/docs/ACCEPTANCE.md)。

浏览器仅请求同源 Host，企业运行凭据不进入浏览器。Host 使用企业身份服务核对当前成员，企业服务限制有效同组织接收人及分享双方读写权限。每次访问核对 v1 协作契约；提交和回复采用去重键，文件验证 SHA256。下载也重新核对双方权限，返回文件副本，不暴露本地路径。

通过公开 `./member` 的 `enterpriseMemberCollaboration(adminUrl, memberAuthorization)` 在企业 Host 显式安装。`memberAuthorization` 是仅 Host 持有、固定成员的有效 Bearer 登录回调；禁止写入序列化 Profile、客户端或模型。每次请求经企业身份和 `/api/auth/me` 比对账号/组织，并检查 v1 协作契约。旧 Runtime 凭据分支和自动静态 patch 已删除。Agent 工具只按成员明确要求查询、分享和回复，不因模型建议自动发送；卸载注销工具与路由，后台保留共享记录。

## 当前验证边界

当前单账号进程构建清单和 Profile 尚未安装此插件；它仍是独立外置包。公开成员 factory 与授权单元测试不等于真实部署安装验收；后续需显式安装并验证成员绑定、撤销、共享与文件读写。

共享文件总量上限 5 MiB；本地验证使用数据库保存不可变快照。当前提供下载及普通回复，不提供共同编辑、自动同步新版文件、任意多轮选取或所有格式的内嵌预览。生产文件存储、容量与保留策略、跨组织、离线恢复和主动推送需另行设计。
